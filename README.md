# Automatic Poster Generator (A4)

Local web page to generate an **A4 poster** for Project Shelter events (handing over / foundation laying) by entering event details and exporting **PNG** or **PDF**.

## Run

1. Open a terminal in this folder.
2. Install:

```bash
npm install
```

3. Start:

```bash
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`).

## Use

- Fill beneficiary name, house no, address, date/time, and QR value (e.g. Google Maps link)
- Optionally upload a top photo + logo
- Click **Download PNG (A4)** or **Download PDF (A4)**
